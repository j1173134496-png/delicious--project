# 八条本地素材

应用 v1.4 继续提供四级八条的透明 RGBA PNG，每个形态只接入 `idle.png`。资源路径统一以小程序根目录 `/assets/...` 表达，由 `models/cat.js` 的 `FORM_META` 作为唯一形态清单；页面不再维护另一套图片路径。应用版本升级不改变数据 schema 4/1.3。

资源预算由 `node scripts/audit-assets.js` 检查：每张形态图长边不超过 640px、单张不超过 450 KiB、四张合计不超过 1.6 MiB，`miniprogram/` 非空文件预估不超过 2 MiB。该结果是导入前源文件预算，不等同于微信开发者工具的压缩包报告。

目前没有 `happy`、`eating`、`sad` 的专用 PNG。互动状态使用共享状态元数据和 CSS 动画；状态图片缺失时继续使用 idle 图，图片加载失败时回退 Emoji。菜谱和情侣照片仍由用户上传或使用占位图。

替换猫咪素材时保持对应形态目录和 `idle.png` 文件名，并重新运行资源审计，不需要修改业务逻辑。
